# Support

Use [GitHub Issues](https://github.com/chigwell/Arbiter-House/issues) for questions, bug reports, and feature suggestions about Arbiter House.

Before opening an issue, check whether someone has already reported the same problem.

For a bug report, please include:

- A short description and steps to reproduce the problem.
- What you expected and what actually happened.
- Your device model, iOS or iPadOS version, and app version or build, if available.
- A screenshot or screen recording, if it helps explain the issue.

Issues are public. Please remove personal information from screenshots and do not post passwords, access tokens, or other sensitive information.

Arbiter House is currently an early prototype. Support is provided through this issue tracker without a guaranteed response time.
