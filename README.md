# Arbiter House

Arbiter House is an early native app for iPhone and iPad. The current prototype features a short animated welcome and a simple “Hello, world!” screen, styled with warm parchment colors and a prismatic horizon.

This repository hosts public documentation and support for Arbiter House. Application source code is maintained separately.

## Support

For questions, bug reports, or suggestions, [open an issue](https://github.com/chigwell/Arbiter-House/issues). See the [support guide](SUPPORT.md) for what to include.

## Project status

The app is under development and has not been released on the App Store. A privacy policy will be published here before public distribution.
